# 🚗 Car Rental Management System

A web-based **Car Rental Management System** developed using **PHP**, **MySQL**, **HTML**, **CSS**, **JavaScript**, **Bootstrap**, **jQuery**, and **AJAX**. The system enables customers to browse available vehicles, book rentals online, and manage reservations, while administrators can efficiently manage cars, bookings, customers, and payments.

---

## 📌 Features

### 👨‍💼 Admin Module

- Admin Dashboard
- Manage Cars
- Manage Car Brands
- Manage Vehicle Categories
- Manage Customers
- Manage Bookings
- Booking Approval & Cancellation
- Payment Management

### 👤 Customer Module

- User Registration & Login

- Contact Support

# 🚀 Installation

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/Car-Rental-System.git
```

---

## 2. Move Project

Copy the project folder into:

```text
xampp/htdocs/
```

---

## 3. Start XAMPP

Start the following services:

- Apache
- MySQL

---

## 4. Create Database

Open **phpMyAdmin**

Create a database named:

```text
carrental
```

Import the SQL file from the **database** folder.

---

## 5. Run the Project

Open your browser and visit:

```text
http://localhost/Car-Rental-System/
```
